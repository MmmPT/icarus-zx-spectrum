# ICARUS v1.0

The first public release of ICARUS for the ZX Spectrum 48K.

## Download

Upload `release/Icarus_ZX_Spectrum_v1.0.zip` as the release asset.

## Highlights

- Seven levels
- Zeus, Cronos and Medusa
- Combo and high-score systems
- Keyboard and Kempston support
- Complete TAP with loading screen
