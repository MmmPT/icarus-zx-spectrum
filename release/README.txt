ICARUS — ZX SPECTRUM 48K
================================

Only the brave defy Zeus.

ICARUS is an original score-chasing arcade game for the ZX Spectrum 48K.
Collect stars, avoid Zeus's attacks, build combos, face Zeus, Cronos and
Medusa, and try to enter the Top 5.

CONTROLS
--------
O / P              Move
Kempston joystick  Move
SPACE              Pause
M                  Toggle music
Any key            Start or continue when prompted

HOW TO LOAD
-----------
Real ZX Spectrum:
1. Type LOAD ""
2. Press ENTER.
3. Start the tape or play the TAP file using your chosen device.
4. The game loads and starts automatically.

Emulator:
1. Open or insert Icarus.tap.
2. Start tape playback if it does not begin automatically.
3. The game loads and starts automatically.

COMPATIBILITY
-------------
ZX Spectrum 48K or compatible model/emulator. Compatible 128K models use
AY music; the game remains playable on a 48K machine.
